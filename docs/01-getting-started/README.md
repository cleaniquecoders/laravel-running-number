## What is Laravel Running Number?

Laravel Running Number is a package that generates sequential running numbers for your database records. It's perfect for creating invoice numbers, order numbers, receipt numbers, or any other type of sequential identifier in your Laravel application.

## Key Features

- **Sequential Generation**: Automatic sequential number generation per type
- **Database Persistence**: State stored reliably in your database
- **Configurable Formatting**: Customize padding and formatting to your needs
- **UUID Support**: Built-in UUID support for running number records
- **Native PHP Enums**: Modern PHP 8.1+ enum support with Traitify
- **Extensible Design**: Easily extend via contracts (Generator, Presenter)
- **Developer Friendly**: Helper functions and facade support
- **Well Tested**: Comprehensive test coverage
- **Wide Compatibility**: Supports Laravel 9-12 & PHP 8.1-8.4

## Requirements

- PHP 8.1 or higher
- Laravel 9.x, 10.x, 11.x, or 12.x
- Database (MySQL, PostgreSQL, SQLite, SQL Server)
